## 3. Chưa test trên bản deploy

- Xuất bản nội bộ + thư viện (chờ deploy `843e436`).
- Các luồng Admin: danh sách tổ (admin thấy tất cả), cấp tài khoản, gán thành viên, sửa template (`recommendedSubjects`, `defaultVisualTheme`), AI usage.
- Render lại / huỷ / retry job.

## 4. Quy trình deploy có migration

Render đang tắt Flyway (`SPRING_FLYWAY_ENABLED=false`). Commit nào có migration mới thì **chạy migration lên DB prod trước**, kiểm tra Hibernate validate, rồi mới push/redeploy. Push trước sẽ làm deploy fail (Render giữ bản cũ).
