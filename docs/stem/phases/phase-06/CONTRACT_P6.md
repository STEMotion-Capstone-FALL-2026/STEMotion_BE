## AI operations và authority

- Grounded operations chính xác: `generate`, `resegment`, `grade`, `extract`, `terms`. Metaphor/approaches/storyboard/alignment/Create không mở. Thêm route additive `/api/v1/ai/scripts/{projectId}/grounded` cho Writer của project có draft/brief; reuse AiScriptService/AiGateway, không endpoint approve. Route legacy giữ nguyên và không được gọi grounded.
- Request schema `stem-ai.v1`: operation (một trong 5), scriptVersionId, expectedScriptRevision, expectedBriefRevision, expectedModeRevision. Server lấy actor, subject/grade/topic/brief/text/scenes/catalog/conditions từ đúng target. Không nhận stemContext/prompt/rule/source-status/PASS do client. Request object unknown/root fields bị400, text/key bounds của P3 (text4000/key128), raw<=262144bytes/depth16; revisions nonnegative required. LLM không có quyền activate/approve.
- Resolver authorize member + active WRITER, current editable version và brief revision/mode; load immutable catalog closure policy/topic/outcomes cùng parent/source (max200), không latest editions. Grade/subject/outcome mismatch và orphan refs dùng deterministic checks BE. Context schema `stem-ai-context.v1`, gradeKey, subjects/outcomes/editions/brief/evidence/scenes, profile PRIMARY_DRAFT khi resolved educationLevel PRIMARY hoặc gradeKey 1–5 dạng số (profile chọn ngôn ngữ là product heuristic, không mapping curriculum/VERIFIED); nếu grade không đủ không tự nhận PRIMARY verified. Labels DRAFT/UNVERIFIED; scientific thiếu findings advisory.
- Gọi model ngoài transaction; resolver transaction kết thúc trước gọi và re-resolve toàn target sau trả. Context digest khác/revision đổi→409 STEM_STALE_TARGET, không ghi script/brief. Response: operation/result/model/requestId/elapsedMs + grounding `{schemaVersion,target,contextDigest,verificationStatus,profile,objectiveKeys,activityKeys,warnings}`. Refs response do server liệt kê từ brief; không cho model invent trusted mapping. Scene output vẫn legacy schema và validators; AI grade score không STEM pass.
- Java và Python nhận cùng JSON context serialized được server dựng. Add optional internal `stemContext` vào ScriptInput/AnalysisInput (`extra=forbid` giữ), explicit max262144bytes/depth16/list200/string4000, schema version. Legacy requests null vẫn chạy như cũ. Java embedded dùng context-data section và instruction chung; remote Python dùng cùng section/instruction profile. Reject model output chứa forbidden authority/source/outcome refs ngoài context; refs chọn lọc là suggestion untrusted.
- Accept giữ endpoint hiện hữu chỉ log quyết định, không persist script. Grounded panel chỉ xem/accept/ignore; **không tự copy scene/evidence/brief**. Khi chấp nhận gửi optional groundingTarget tới decision handler và recheck cùng resolver trước decision. Muốn sửa nội dung: Writer tự sửa rồi explicit Save Draft qua path cũ; không có “apply generated script” transaction ở P6. Không hứa atomic AI apply/save hay full Create flow; invalid manual/AI-origin content đều chịu validator/write permissions cũ. Nếu cần one-click apply tạo scene thì scope riêng.
- Khóa guard/limits và authority tại route grounded trước call; legacy route không bị STEM gate mới. Không giữ DB locks trong provider call. Q03 fake/offline chỉ trong test injection ở provider boundary, không thêm fake public production endpoint. No keys thật; prompt/context có thể nhạy cảm, log báo cáo chỉ refs/hash và status.

Stable order publication.published_at DESC, publication.id DESC. Existing sort no-paging P5 tests không lấy giả thứ tự mutable project.
- Khi P5 artifact feature có bean: query PUBLICATION sidecar LEFT JOIN đúng publication_id, frozen payload không load latest brief/catalog/project metadata. Data/count/filter trước SQL LIMIT/OFFSET; không Java subList/no N+1. Legacy public fields được fallback current project chỉ khi không snapshot, đúng behavior P5; curriculum fields vẫn null/empty và LEGACY_UNMAPPED, không suy từ raw label.

DB-side DISTINCT json refs và bounded values, không fetch toàn bộ row JSON vào JVM. Chưa khẳng định full performance production, không migration/index mới.
